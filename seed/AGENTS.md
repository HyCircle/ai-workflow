# AGENTS.md — 通用 agent 指令(常驻)

> 本文件是所有 agent(Claude Code / Cursor / Codex / 无头 worker)进项目**第一份读**的东西:
> 常驻工作纪律 + 项目工具约定。`CLAUDE.md` 软链接到本文件,一份内容三家共读。
> 保持短——§0 的全部价值就在"短到一定被读完"。

## 0. 常驻工作纪律(每次干活都读)

**脊椎:开发期「少即是多」。默认不加;加任何东西(补丁层 / 兜底 / 抽象 / 边界处理 / 测试)之前,先证明它非加不可——有真实触发路径,不是想象的。**

1. **别 patch-on-patch。** 新功能与旧的不兼容时,不加兼容层 / adapter,**掀掉地基整体重构成更通用、更精简的实现**。补丁摞过两层就是信号:回头问「底层的数据表示 / 抽象搞对没有」,而不是再补一层。(无历史包袱的场景——如单用户 demo——契约改名直接清库重建,别背兼容层。)

2. **别下意识加兜底。** 兜底是**项目成熟后**的选项;开发阶段要**尽量暴露问题、直面并解决**。**静默的、无条件的、产出最坏结果的兜底是最贵的 bug**——它把「最坏情况」固化成默认行为,还不留信号,查起来要翻库逐字比对。真要兜:必须**安全降级 + 打点自曝**(log + trace),绝不静默 `= {}` / 拷贝最坏值了事。

3. **别过度设计。** 不为**不存在的边缘情况**写代码 / 测试 / 文档。LLM 注入上下文后自己就会做的对话级觉察,别用确定性代码去实现(检测情形 X→机械做 Y 多是无效复杂化);确定性硬拦只在**有不可逆副作用**时才值(真下单 / 真删 / 真发钱),可逆动作用硬拦是大炮打蚊子。连带清**死脚手架**:建了没消费者的表 / 字段 / 闸门。

4. **别凭记忆 / 假设写代码,先读实况。** 动手前先看真身:读那段代码、跑一眼数据、查真 API 签名,别从记忆或直觉脑补前提往下写(这是 vibe coding 的头号翻车点)。**代码 + 数据是 SSOT**;凭记忆手写枚举 / 前缀 / 阈值必漏,手边有全量表就从数据反推。

5. **测试要能真的失败。** 测**会崩的接缝**(跨模块信号传递:谁在什么时候取到的值是不是活的),别堆测不出问题的重言式 / mock 剧场。一个不可能失败的测试是**负资产**——占行数、给假安全感、还要维护。判据尽量写成「bug 在时会红」。

6. **正面写,别刻疤。** 指令 / 文档 / 注释只说**现在该怎么做**,别把「上次怎么摔的」编进去。读者(下一个 agent / 未来的你)没经历你的事故——防御性括注(「(已踩)」「否则会 X」)、靠否定失败模式来强调(「就一趟」「别被框住」),只让他为没打过的仗分神,还常把你想避开的坑反而种给他。要传达的行为正面说一遍就够(「跑一遍,输出清单」,而非「别跑成循环」);给**前向的理由**(「实现的家在代码 + 测试」)、不给**后向的事故**(「上次搬了出事」)。真成了通用铁律就升进本节,别每处复述。

## 项目工具约定

具体命令与模型档位是**单机 / 项目级配置**,唯一改 `.claude/workflow.env`(gitignored,换项目 / 换模型只动那一处)。scripts 从它取默认值,skill 里的命令示例以它为准。**当前项目栈:`<填,如 Python + uv>`**——在 `.claude/workflow.env` 填 `WF_TEST_CMD` / `WF_PY`。

**派单模型分档**(便宜劳力,写法「后端/模型」,后端 `cursor|codex`,省前缀=cursor):
- `WF_WORKER_MODEL` — 默认执行(量大最省)。
- `WF_REVIEW_MODEL` — 默认验收(**跨厂异构** worker,真独立第二双眼)。
- `WF_REVIEW_MODEL_STRONG` — 高危双验收的第二审 / 硬骨头。

换型号 / 换厂就改这三个别名的值,不要在脚本或 skill 里写死具体型号。

## 文档系统(冷启动读这张地图)

一类信息一个家(全景见 `docs/workflow.md`):
- **AGENTS.md**(本文件)= 常驻纪律 + 工具约定 + 本地图。
- **architecture.md** = 当前设计现状/地图(各 ADR 的合成视图,冲突时 ADR 赢)。
- **decisions/**(ADR)= 冻结决策(why + 可测契约 + 证据),`ADR-NNNN` 引用(ADR 多了再加 `index.md`)。
- **TODO.md** = 扁平的"下一步";设计债不进这、进 ADR。
- **scratchpad/** = 临时产物(gitignored)。

冷启动顺序:AGENTS(本页)→ architecture(现状)→ TODO(下一步)→ 相关 ADR。
